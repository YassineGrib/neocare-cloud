# NEOCARE Clinic - Brand Typography

This document defines the typography system for NEOCARE Clinic.

---

## 1. Brand Font: **IBM Plex Sans Arabic**
The official brand font is **IBM Plex Sans Arabic**. It is modern, friendly, confident, and elegant.
It is used for all main headings, subheadings, and body text.

### Available Weights
The font must be used in its designated weights based on hierarchy:
1. **Thin**
2. **Extra Light**
3. **Light**
4. **Regular**
5. **Medium**
6. **Semi Bold**
7. **Bold**

---

## 2. Alignment & Direction
- **Arabic Text:** Always **right-aligned** (من اليمين إلى اليسار).
- **English Text:** Always **left-aligned** (من اليسار لليمين).

---

## 3. Typographic Hierarchy
The guidelines define standard sizing and leading relationships:

- **Main Headline:** Bold, `72pt` size / `56pt` leading.
- **Section Heading:** Semi Bold, `45pt` size / `36pt` leading.
- **Sub-headline:** Medium, `36pt` size / `28pt` leading.
- **Body Text:** Regular, `10.5pt` size / `12pt` leading.

---

## 4. Type Setting & Writing Rules

To ensure a clean and consistent brand style across digital copy:

### alternatives (الخيارات البديلة)
- In non-scientific contexts, use a **pipe (|)** instead of a slash (/) to express alternatives.
  - *Example:* `English | Arabic` (Correct) vs `English/Arabic` (Incorrect).

### URLs & Website Addresses
- Write URLs without `www` unless it is technically required.
  - *Example:* `neocare.clinic` (Correct) vs `www.neocare.clinic` (Incorrect).

### Phone Numbers (أرقام الهواتف)
- Write telephone numbers without dots, pipes, or slashes.
- Use **blank spaces** to divide digits.
  - *Example:* `+965 123456789` or `1888 828` (Correct).
  - *Example:* `+965.1234.5678` or `1888-828` (Incorrect).

### Paragraph Spacing
- Use two default line breaks to separate paragraphs.
