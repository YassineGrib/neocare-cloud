## 3. How to Use on Nextcloud
To change the active background for the server instance to one of these files:
1. Log in as **Admin**.
2. Go to **Administration Settings > Theming**.
3. Under the **Background and login image** field, upload your preferred file from the backgrounds directory:
   `/Users/bmg/Development/workspace/nextcloud-whitelabel/docs/brand-assets/backgrounds/`
   * `neocare-bg-fluid.png`
   * `neocare-bg-glass.png`
   * `neocare-bg-organic.png`
   * `neocare-bg-poly-dark.png`
   * `neocare-bg-poly-light.png`
   * `neocare-bg-silk.png`
   * `neocare-bg-topo.png`
